# Flappy Dog

A lightweight, fast, and responsive Flappy Bird clone featuring a flying dog!

## Features

- **Flying Dog Character**: Custom vector-like art drawn directly on the HTML5 Canvas.
- **Responsive Design**: Works on desktops, tablets, and mobile devices.
- **Modern UI**: Clean interface with smooth animations and backdrop blur.
- **High Score**: Saves your best score locally.
- **Lightweight**: No external image assets or heavy frameworks. Pure HTML, CSS, and JavaScript.

## How to Play

- **Desktop**: Click the mouse or press the Spacebar to fly.
- **Mobile**: Tap the screen to fly.
- Avoid the green pipes!

## Development

Built with vanilla JavaScript and HTML5 Canvas.
