# Flappy Doge (JavaScript)

A lightweight Flappy Bird-style game where the bird is a **flying dog**.

## Run locally

Any static file server works.

Example (Python):

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Controls

- **Flap**: Tap/click, `Space`, or `↑`
- **Mute**: `M`

## Notes

- Pure HTML/CSS/JS (no dependencies, no remote assets).
- Responsive and high-DPI canvas rendering.
- Best score is saved in `localStorage` on this device.
